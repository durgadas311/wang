# Wang
## An Ode to Wang Laboratories' Programmable Calculators

DISCLAIMER: This project was my first dalliance into JAVA,
and it began life extremely monolithic.
It has since been slowly evolving into "better JAVA code".
Keep your barf-bag handy.

Some subdirectories of interest:

#### w600-sim
> The core simulation code for the Wang 600 series.

#### w700-sim
> The core simulation code for the Wang 700 series.

#### w1200-sim
> The core simulation code for the Wang 1200 Word processor, based on Wang 600 hardware.

#### common
> Common code to all simulators.

#### wang-docs
> Various documents/schematics collected over time.

#### w600-asm
> A tool to assist in writing and testing microcode for the Wang 600.

#### w700-asm
> A tool to assist in writing and testing microcode for the Wang 700.

#### wasm
> An effort to create a "source code language" for writing Wang 600 and 700 programs.
