Running Environment

The simulator recognizes the following environment variables:

WANG700HOME
Path to wang700 files, default is ~/Wang700Files.
WANG700_FONT
Font to use for display. Default is Panaplex9seg.ttf.
WANG700_HOST
Hostname of back-end server, see -w option.
WANG700_PORT
Port to use for connecting to back-end server, see -w option.

The simulator is normally started with the following command: 

    java -jar wang700.jar

    which starts up the GUI front-end. This will attempt to run the command: 

      ./w700-sim -b

    which will start up the simulator back-end.

An alternative is to run the GUI as a client to the back-end on a remote host. In this case, the simulator is started with: 

    java -jar wang700.jar -w [ <host> <port> ]

    The <host> and <port> arguments are not needed if the environment variables have been set. The remote <host> must be listening on the correct <port> number and should start up the back-end using the command: 

      /path/to/sim/w700-sim -b -w

    and may require other options, for example to get the path to the microcode image.
