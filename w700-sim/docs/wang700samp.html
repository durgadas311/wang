Sample Programs

See "Using the Tape Drive" for instructions on how to load programs, and to verify the program loaded correctly.

countdown.w7t - Count Down timer

VERIFY PROG: 199

USE: Enter a number and press GO. This display will count down that number until 0.

This program demonstrates basic use of WRITE-ALPHA 1/X (Pause) and program loops.

celsius.w7t - Convert Degrees Fahrenheit to Celsius

VERIFY PROG: 112

USE: Enter degrees Fahrenheit and press GO. The display will show the equivalent degrees Celsius.

This program demonstrates how to do basic math calculations using registers.

factorial.w7t - Compute factorials (N * N-1 * N-2 * ... * 1)

VERIFY PROG: 336

USE: Enter number and press GO. The display will show the factorial of that number. Note that the calculator overflows with numbers somewhere above 55.

hex2dec.w7t - Converting HEX to decimal

VERIFY PROG: 1020

USE: Enter HEX digits using the subroutine keys, with all switches off (00). The equivalent decimal number is maintained in the display.

hello.w7t - Simple Example of the Model 701 OutputWriter

VERIFY PROG: 176

  • If not already done, use the Devices -> Device... menu to connect one of the OutputWriter models (701, 702, or 711).
  • Press GO

The OutputWriter window should appear with the text "Hello World!" printed on it.

This program demonstrates how to print a text string to the OutputWriter.

prime_nums.w7t - Find Prime Numbers

VERIFY PROG: 888

  • If not already done, use the Devices -> Device... menu to connect one of the OutputWriter models (701, 702, or 711).
  • Press GO.

Prime numbers will be printed on the OutputWriter in tabular format, 8 primes per line.

The program stops 10,000,000,000, however is probably desirable to stop it sooner (press PRIME).

calendar.w7t - Prints one month calendar on OutputWriter

VERIFY PROG: 5032

  • If not already done, use the Devices -> Device... menu to connect one of the OutputWriter models (701, 702, or 711).
  • Enter month (1-12), press GO
  • Enter year, press GO

The OutputWriter window should appear with the calendar for that month and year printed.

craps.w7t - Game of Craps

VERIFY PROG: 2332

USE: Optionally enter a random number (use decimal places), then press GO. The number 500 should appear on the Y display. This is your bank. Enter a bet and press GO. The first dice roll will appear for 1.4 second. If it is a win, the display will flash for 0.7 second and then you will see your new bank and can enter a new bet. If it is a lose, the display will blank for 0.7 second and then you will see your updated bank and can bet again. If the number is a "point" then it is placed in Y, and X will show repeated dice rolls for 0.7 second each, and the appropriate action taken (win, lose, repeat).

This program demonstrates use of the random number generator and simple game simulation. It also shows use of "special effects" like making the display flash without aborting the program, and making the display blank.

zeller.w7t - Compute day-of-week for give date

VERIFY PROG: 2803
  • If not already done, use the Devices -> Device... menu to connect one of the OutputWriter models (701, 702, or 711).
  • Enter month (1-12)
  • Press GO (The OutputWriter window should appear, may need to raise calculator window to continue)
  • Enter day (1-31)
  • Press GO
  • Enter year (4 digit)
  • Press GO

The OutputWriter window should appear with the entered values and result. The numeric value computed using Zeller's Congruence is printed, along with the name of the day.

graph_sin.w7t - Example of Plotting Graphs on the 702 Plotting OutputWriter

VERIFY PROG: 2159

  • If not already done, use the Devices -> Device... menu to connect the 702 Plotting OutputWriter.
  • Press GO.

A graph of a sine-wave will be printed, in landscape orientation (going down the page). A title will be printed at about the center of the graph (180 degress).

plot_dat.w7t - Plots data samples from a "paper tape" file

VERIFY PROG: 4784

  • If not already done, use the Devices -> Device... menu to connect the 712 Flatbed Plotter and the 703 Papert Tape Reader.
  • If not already done, use the 703 Paper Tape Reader menu to install (or rewind) the paper tape image "temperature.wdf".
  • Press GO

The graph of the temperature data, with axii and labeling, will appear on the plotter window.

Data file image is "plain text". The Wang "Paper Tape Editor", as it was called, took standard 8-level ASCII code on paper tape. Image files are thus plain (ASCII) text, formated as lines of numeric data.

example707.w7t - Demonstrates using the Model 707 Teletype interactively

VERIFY PROG: 880

  • If not already done, use the Devices -> Output Devices menu to connect the 707 Teletype.
  • Using "telnet", or some other suitable client, connect to the Wang 700 simulation. Typically, the ASR33telnet.jar app is used instead of telnet.
  • Press GO. An introduction and prompt for data should appear on the "telnet" session.
  • From the "telnet" session, type a number and press "Enter" (Return).
  • The equivalent temperature in Celsius, and a new prompt, should be printed.

The program repeats indefinitely, until PRIME is pressed on the calculator. If the client disconnects, the program will still be running and a new client can be connected (although in that case the prompt is not re-printed).

cp_flpy.w7t - Demonstrates copying one floppy data to another

VERIFY PROG: (WIP)

  • If not already done, use the Devices -> Devices... menu to connect the 740 Dual Floppy.
  • Click the left drive and mount a file to be copied.
  • Click the right drive and enter a new file name.
  • Press GO. The drive lights should alternate rapidly.
  • When the program finishes, 315392.0000 should be in the display.

The file mounted on the right drive should now have the same contents as the one mounted on the left drive.
