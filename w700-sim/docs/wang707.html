Notes:

  • The last four codes will generate X OFF in the teletype in addition to the 700 generated codes.
  • All other codes except rub-out are illegal. All illegal codes will be ignored except when preceded by a numeric character. In this latter case an illegal code will generate a GO to the 700 and an X OFF to the teletype.
  • Rub-outs will just be ignored.

Simulator Notes:

  • The teletype glyph "←" has been replaced by underscore (_) on modern keyboards.
  • The teletype glyph "↑" has been replaced by carat (^) on modern keyboards.
  • X OFF stops the paper tape reader.
  • Rub-outs are an artifact of the method used to edit a paper tape, where characters could be deleted by punching over them using all (7 or) 8 columns (binary code 111 1111 or 1111 1111). The simulation treats all out-of-range characters as rub-out.
