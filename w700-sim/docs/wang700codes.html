Wang 700 Program Codes

This section describes all keys on the keyboard (that generate program codes), and what codes are generated. Note, the "Function Toggle Switches" and "Function Keys" are used together to form a complete program code. The toggles are set to the desired code of the first number, and then one of the keys 00 through 15 is pressed to generate the full code.
