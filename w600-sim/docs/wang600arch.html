Architecture of the Wang 600

Microcode Execution Sequence

Unlike modern computer CPU hardware, the Wang 600 does not execute the microcode sequentially. Each microcode instruction contains the address of the next instruction to execute, with the exception of the "return from subroutine" instruction which ignores the "next address" field.

The "next address" may be optionally modified by certain status bits, which affect the low order 2 bits of the address.

A "return from subroutine" instruction pops the previously pushed address off the stack and forces the low bit to "1". This means that all "call subroutine" instructions must be placed at even addresses, or else the return will cause an endless loop. It is not known whether such loops exist in the Wang 600 microcode, either accidentally or intentionally.

Microcode instruction execution sequence is terminated, and a new instruction address is forced, when certain keys are pressed. Because this is handled in hardware, these keys will immediately terminate any operation in progress and force the calculator to perform the function programmed by that key.
