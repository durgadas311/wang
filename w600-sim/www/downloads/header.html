Files and archives related to the "Wang 600 Programmable Calculator simulator"
NEW:
  • All versions now contain a JAVA simulator, and require no externally-compiled C programs. Should run on any JAVA VM platform.
  • Exterimental "compiler" for maintaining Wang 600/700 programs in a source-code format. Requires GNU Compiler tools. See WPCC Documentation
  • Includes "novelty" program to simulate editing a program as Mark-Sense Cards (as in for the 614 Card reader).
